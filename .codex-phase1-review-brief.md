## What to attack

1. **Spec conformance, item by item.** For every Phase 1 workstream item,
   cite the code that implements it or flag it as missing/partial. The
   spec's literal golden expectation sets must match the fixture exactly.
2. **Bypass routes.** The whole point is "blocked means blocked." Find any
   path — endpoint, script, email, CLI tool, cron — that still lets an
   unsealed, unapproved, or blocked order reach a coach or athlete with
   usable artifacts or apply instructions. Grep for the old routes.
3. **Seal integrity.** TOCTOU between seal and approval; anything writable
   after sealing; seal verification actually enforced at every consumer,
   not just computed.
4. **Migration safety.** v1 files: can any code path still read/transition
   them without quarantine? Fail-closed means fail-closed.
5. **Token discipline.** Typed download tokens: audience/artifact/revision
   binding, expiry, and rejection of legacy tokens.
6. **Test honesty.** Tests that assert the old behavior were changed —
   verify the changes weakened nothing (e.g. asserting `processing` where
   `ready` was correct behavior to preserve, vs. correctly reflecting the
   new gate). Flag any test deleted or gutted to make the suite pass.
7. **Scope creep / later-phase leakage** and any renegotiated settled
   decision.
8. **The r9 conditions** that apply to Phase 1 — each one honored or not.
