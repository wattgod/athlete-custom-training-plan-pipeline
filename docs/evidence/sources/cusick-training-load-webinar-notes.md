# Tim Cusick — WKO5 "Training Load" webinar (YouTube vfC-CRkl5Kk), summary notes
Source: Matti's Drive doc "Training Load" (Gemini/notes capture of the webinar). Captured 2026-08-26.

Key claims (timestamps from the doc):
- Training load = cumulative stress; ATL = short-window absolute load, CTL = long-window (42d standard "but with more range to be discussed").
- External load (TSS) is measurable; INTERNAL strain drives adaptation; load is "neutral" — same TSS ≠ same strain.
- Strain/adaptation are non-linear and individual; PMC measures external stress only; coaching art = the variables around it.
- Aging athletes: variation too high to standardize; do NOT hold back by rule; use performance history + analytics.
- CTL by training maturity: lower loads for less experienced, higher for more experienced (maturity = overall training history; injury dents CTL but not maturity).
- **Ramp rate: increase 5–8 TSS/day CTL per week, for 2–4 weeks in a row, for most athletes** — ramp "hits ATL first and translates into CTL"; more impactful lever than absolute CTL.
- Track CTL via weekly summary + gain, not a rolling ramp chart.
- Running: less efficient, more impact/trauma → runner ramp rates need history-aware discounting.
- TSB is the load-management key for "achieving optimal performance" (final section; doc truncates).
